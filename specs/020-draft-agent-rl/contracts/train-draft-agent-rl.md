# CLI Contract: `python -m draft train-draft-agent-rl`

**Feature**: 020-draft-agent-rl | **Date**: 2026-06-13

The one new command. Rollout generation and evaluation reuse the unchanged
`generate-draft-data` / `analyze-generated-decks` (see quickstart.md). Mirrors
the `train-draft-agent` subparser conventions (lazy import, resumable flags
`default=None`, architecture flags forbidden on load).

## Synopsis

```
python -m draft train-draft-agent-rl \
    --checkpoint <reference.pt> \
    --drafts-path <on-policy-corpus.jsonl> \
    --learner-agents <label[,label...]> \
    [--critic-corpus <corpus.jsonl> ...] \
    [--rollout-temperature 1.0] [--gae-lambda 0.95] \
    [--kl-coef 0.1] [--entropy-coef 0.01] [--value-weight 1.0] \
    [--lr ...] [--batch-size ...] [--epochs ...] [--val-fraction ...] \
    [--evals-per-epoch ...] [--patience ...] [--warmup-frac ...] \
    [--max-grad-norm ...] [--lr-decay-patience ...] [--lr-decay-factor ...] \
    [--min-lr ...] [--cards-path output/cardsfolder/] \
    [--resume <rl-run.pt>]
```

## Flags

| Flag | Required | Default | Resumable | Meaning |
|---|---|---|---|---|
| `--checkpoint` | yes (xor `--resume`) | — | no (it *is* the load) | Reference πₖ: warm-starts actor+critic, KL anchor, must have generated `--drafts-path`. Bootstrap-from-weights. |
| `--drafts-path` | yes | `output/draft/drafts.jsonl` | yes | On-policy corpus; sole policy-gradient source. |
| `--critic-corpus` | no (repeatable) | none | yes (list) | Extra off-policy corpora, critic regression/coverage only — never the policy gradient. |
| `--learner-agents` | yes | — | yes | Comma-separated whitelist of mix labels feeding the policy gradient. Must be non-empty. |
| `--rollout-temperature` | no | `1.0` | yes | T the corpus was sampled at; all policy distributions use it. MUST match the `generate-draft-data --temperature` that produced the corpus. |
| `--gae-lambda` | no | `0.95` | yes | GAE λ (γ fixed at 1.0). |
| `--kl-coef` | no | `0.1` | yes | Initial KL-anchor coefficient (val-driven schedule). |
| `--entropy-coef` | no | `0.01` | yes | Initial entropy-bonus coefficient (val-driven schedule). |
| `--value-weight` | no | `1.0` | yes | Critic-MSE coefficient. |
| `--lr`, `--warmup-frac`, `--batch-size`, `--max-grad-norm`, `--epochs`, `--val-fraction`, `--evals-per-epoch`, `--patience`, `--lr-decay-patience`, `--lr-decay-factor`, `--min-lr` | no | gen-1 defaults | yes | Identical semantics to `train-draft-agent`. |
| `--cards-path` | no | `output/cardsfolder/` | yes | `.npz` cache. |
| `--resume` | yes (xor `--checkpoint`) | — | — | Continue an RL run (weights+optimizer+epoch+best+anneal). Architecture + RL hyper-params inherited; CLI flags override resumable ones. |

**Not accepted**: architecture flags (`--d-model/--n-layers/--n-heads/--ff-dim/--dropout`)
— architecture is inherited from `--checkpoint`/`--resume`; passing one fails
fast (exit 2), as in `train-draft-agent`.

## Startup validation (before any training; FR-017, SC-003)

Each failure prints `Error: …` to stderr and exits nonzero:

| Condition | Exit |
|---|---|
| `--checkpoint` and `--resume` both set, or neither | 2 |
| An architecture flag passed alongside `--checkpoint`/`--resume` | 2 |
| `--learner-agents` empty/whitespace | 2 |
| `--rollout-temperature <= 0` | 2 |
| `--checkpoint`/`--resume` file missing | 2 |
| Checkpoint `embedding_dim` ≠ `.npz` cache width | (raised `ValueError`, nonzero) |
| Corpus empty / no usable examples | (raised `ValueError`, nonzero) |
| Architecture inconsistency in loaded config | 6 (`DraftAgentArchitectureError`, as gen-1) |

**No provenance/off-policy rejection** (research D6): a corpus generated by a
different checkpoint is *not* rejected; the run proceeds and the behaviour-anomaly
summary (below) is the only signal.

## Side effects / outputs

- **Stdout**: per-mini-epoch log line — `train`/`val` decomposition
  (`policy`, `value`, `entropy`, `kl`, `total`), held-out RL objective (the
  best-checkpoint metric), per-pack critic MSE, and the live LR when annealing.
- **One-time behaviour-anomaly summary** (FR-009 / SC-004): mean behaviour
  log-prob + fraction of learner picks below the probability floor; a prominent
  warning if that fraction exceeds the anomaly threshold. Never aborts.
- **Checkpoints**: `models/draft/agent/{timestamp}.pt` (best by held-out RL
  objective) + `latest.pt` (every eval), in gen-1 format + `rl_metadata`
  (generation index, reference id, RL hyper-parameters). No encoder weights.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Training completed (best checkpoint written). |
| 2 | Usage / validation error (see table) or missing file. |
| 6 | Architecture inconsistency in a loaded checkpoint. |
| 130 | Interrupted (Ctrl-C). |

## Out of contract (operator runbook, no new code — quickstart.md)

- **Rollout generation**: `generate-draft-data --agent-checkpoint <label>=πₖ
  --pick-mode sample --temperature T --seed S --agent-mix <…> [--set …]`.
- **Yardstick**: `generate-draft-data --pick-mode argmax` over a fixed mix
  co-seating the generations + Forge + a random bot, then
  `analyze-generated-decks --agent <each>` for per-agent mean `deck_score`.
- **Promotion**: manual operator judgment (the system does not auto-promote).
