# Gen-3 model layout

Covers the input slots, the relation-aware trunk and the output heads. Read on demand: `src/effects/CLAUDE.md` says when, and lists the other topic files in this directory.

## Input layout

**Input layout.** Every line of a card is an `[ABILITY]` slot (`slot_lines`, the one list the batcher and the surface builder read), flagged active, granted, granted temporarily (granted by anything but a static), cast with (flag and count) and chosen (`ability_features`, `ABILITY_FEATURE_WIDTH` 7, read by `ability_proj`); a face that is not up gives inactive slots. A keyword keeps a card-level flag only where a Forge card-script selector or engine check names it (`domain/kept_keyword_flags.py`, 85 keywords, written by `scripts/scan_keyword_flags.py` and failing its test when stale; fear, intimidate and ward are not among them); every keyword is also read through its line's reminder text, a line with no key through `keyword-line/<fragment>`. A card slot is a sequence of named parts (`card_segments`): subtypes and chosen creature types index one learned embedding, each named counter a row of `counter_embedding` scaled by its count and by its log1p (the lists are Forge's, `domain/forge_vocabularies.py` from `scripts/scan_forge_vocabularies.py`), and the card, player, global and `[ACT]` facts sit where root § 9.4–9.5 places them. Floating effects and delayed triggers the snapshot gives no entity are card slots after the board's (`command_zone_entities`; `board_entities` is the one card list), their source lines granted ability slots; they are no per-entity target. A dungeon is a card slot with the one keyword line `convert` renders for all its rooms, so a room has no line of its own.

## Relations

**Relations.** The trunk's layers are `domain/relation_attention.py`'s `RelationEncoderLayer`: a pre-norm `nn.TransformerEncoderLayer` under the same parameter names whose attention adds, per layer and head, a learned key vector `K_r` to the score and a value vector `V_r` to the output for each typed relation `r` from slot i to slot j, computed per slot and type and scattered onto the pairs (no vector per pair is built). Both tables start at zero, in the `head` group; `--relation-values off` keeps `V_r` a zero buffer. The 68 types are `domain/relation_types.py`'s 31 families, each forward and reverse, `targets` one per index 0, 1, 2 and one for 3 and above; their order is a checkpoint's table rows. `_SlotRelations` in `effect_head_input.py` builds each record's `(N, 4)` `[batch, from, to, type]` triples once the slots are fixed, after context dropout and gate 2's strip: the record's `links`, plus the four families the reader builds (`line_of`, `line_of_the_same_card`, `mode_of`, `has_the_same_name`) and `[ACT]`'s `targets` and `source_of`; a line end with no slot reads its card's, a link to an object with no slot is dropped. The shard line prints the tables' pre-clip norms (`rel_k_norm`, `rel_v_norm`); `scripts/measure_trunk_step.py` measures a step on a curated shard.

## Outputs

**Outputs.** The per-entity head holds 300 fields (`effect_head_layout.PER_ENTITY_FIELDS`, root § 11.2–11.3: copies, designations, class levels, face after, the player designations, subtypes, supertypes and abilities gained and lost, base P/T deltas, damage prevented, signed deltas per named counter, `keywords_gained`/`_lost` over the closed keyword list, …); the verdict head gains `timing`, one column per `PlayabilityCheck`, a cost-adjustment delta per mana symbol (supervised on casts only), `resolution_outcome`, `effects_created` and `replacement_result`; a new shipped `global` head reads `[GLOBAL]` (turn-structure changes, day/night change); the created-objects slots gain counters, an other-controller bit, a kind, subtypes and keywords. The subtype and keyword lists are `domain/output_vocabularies.py`, regenerated from a built manifest by `scripts/scan_output_vocabularies.py --manifest`. A field takes a silent value only where the collector writes its event for every occurrence; `protector_changed` has no source yet (Forge publishes nothing), so it never trains.
