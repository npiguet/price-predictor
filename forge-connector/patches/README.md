# Forge engine patches

`0001-Add-effect-record-instrumentation-hooks.patch` is applied to the **sibling `../forge`
checkout**, not to anything in this repository. It adds the hooks the effect-record collectors need
for exact attribution; without it the collectors still run, fall back to bracket attribution, and
stamp every record `"mode": "degraded"`.

**It must be re-applied after every Forge upgrade.** Forge is rebuilt independently of this repo and
an upgrade reverts it, which is why attribution mode is detected at worker startup rather than being
a build flag: a lapsed patch mislabels a corpus otherwise.

Nothing in this repository depends on the patch being applied. The connector builds against **stock**
Forge, reaches every hook reflectively, and falls back to bracket attribution when it finds none — so
an unpatched checkout collects a `degraded` corpus rather than failing.

## Applying

```bash
cd ../forge
git checkout -b effect-record-hooks
git am ../price-predictor/forge-connector/patches/0001-*.patch
mvn -pl forge-core,forge-game,forge-ai -am install -DskipTests
```

Then rebuild the connector, because the worker links against the freshly installed Forge jars:

```bash
cd ../price-predictor/forge-connector && mvn package -DskipTests
```

The patch is generated by `git format-patch` from that branch, so `git am` replays it as a commit and
a later Forge upgrade is a rebase rather than a re-apply. Regenerate it after amending the branch:

```bash
cd ../forge
git format-patch -1 HEAD -o ../price-predictor/forge-connector/patches --no-numbered
```

## Verifying

```bash
python -m pytest tests/integration/test_effects_patched.py -m integration
```

Three tests, and they read the environment rather than assuming it: on a stock checkout they skip, on
a patched one they assert the mode is `patched`, that a run reaches the unlocked record kinds, and
that snapshots carry tier 3. A short collection is the other check — records carry `"mode": "patched"`
and the worker prints the detected mode at startup.

## What each hook is for

| File | Hook | Unlocks |
|---|---|---|
| `TriggerHandler` | per-thread pointer to the running trigger (`get`/`setEffectRecordCause`) | cause attribution; **this is the hook mode detection probes for** |
| `TriggerHandler` | listener at the condition evaluation (`setEffectRecordTriggerListener`) | `trigger` records, fired and not |
| `ReplacementHandler` | listener around `executeReplacement` (`setEffectRecordListener`) | `rewrite` records |
| `AbilityUtils` | per-thread pointer to the resolving sub-ability (`getEffectRecordSubAbility`) | per-clause attribution |
| `AiController` | rules-level candidate verdicts (`setEffectRecordPlayabilityListener`) | `playability` records |
| `AbilityManaPart` | listener where produced mana reaches the pool (`setEffectRecordManaListener`) | mana records, and with them the role-polarity probe |
| `Card` | keyed accessors for the type and colour layer tables | the `continuous` record's type and colour channels |
| `GameAction.destroy` | `AbilityKey.Cause` in the `Destroyed` run parameters | a destroy record can name what destroyed the permanent |

The hook names are a contract with `PatchHooks` and `PatchedCollectors`, which look them up by string.
Renaming one on either side degrades the corpus silently rather than failing the build — that is the
cost of building against stock Forge, and why the integration test asserts the mode.

## Not yet hooked

`playability-legality` is the one sampling class a patched run still misses. It is the legal attacker
and blocker sets, which `AiAttackController` and `AiBlockController` compute and discard; nothing
reads them, so a patched run reaches seven of the eight classes.

The `continuous` record's type, colour and name channels are also still empty. The keyed accessors
exist and the reader fills `pt_boost` and `keywords` from the P/T and keyword layers, which is where
anthems and keyword grants live; types and colours need the applied change diffed against the base,
which the flattened accessors make awkward and nobody has needed yet.
